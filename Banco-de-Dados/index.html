Modelagem & Administração de Dados

Olá, Administrador de Dados! 👋

Seja bem-vindo à plataforma prática de Banco de Dados 101 para a Turma 101. Aqui você aprenderá a planejar, transformar e organizar dados de sistemas digitais!

O que estudaremos nesta trilha?

  • 🔍 Fundamentos: Compreender a diferença entre Dados, Informação e Conhecimento.
  • 🗄️ SGBD: O papel do gerenciador, os 4 pilares e os modelos de dados.
  • 📐 Modelo ER: Criar plantas de dados com Entidades, Atributos e Cardinalidades.
  • 🔄 Mapeamento Relacional: Traduzir diagramas DER em tabelas com Chaves PK e FK.
  • 🧼 Normalização: Organizar e limpar as tabelas aplicando a 1FN, 2FN e 3FN.
