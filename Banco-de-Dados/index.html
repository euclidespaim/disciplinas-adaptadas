Prática em Laboratório

Sequência didática

Depois da aula 7 (Fundamentos de SQL), a turma passa a usar SQL de verdade, no SQLite, pela linha de comando. Cada prática é um roteiro guiado: você digita, compara com o que deve aparecer e depois resolve sozinho.

Como funciona cada prática

1Digite e compare

O roteiro mostra o comando e o que deve aparecer na tela. Se a sua tela ficou diferente, procure o erro antes de seguir.

2Erre de propósito

Alguns comandos estão errados de propósito. Ler a mensagem do banco faz parte da aula.

3Faça sozinho

No fim, você escreve os comandos. O roteiro diz quantas linhas devem aparecer, para você conferir.

Pergunta para responder

Cada parte termina com uma pergunta. Responda no caderno, com as suas palavras.

Ferramentas do laboratório

VS Code

O terminal do VS Code (menu Terminal > Novo Terminal) é onde você digita os comandos.

sqlite3

O SQLite pela linha de comando. Abre o banco, que é um único arquivo na sua pasta, e executa o SQL.

DB Browser for SQLite

Programa para ver as tabelas em uma janela. Use só para olhar: o trabalho da prática é no terminal.

Objetivos

  • Abrir um banco SQLite pelo terminal e usar os comandos com ponto (.tables, .schema, .read).

Preparação

10 min

  1. Na pasta Documentos, crie uma pasta chamada sql.

  2. No VS Code, use o menu Arquivo > Abrir Pasta e escolha a pasta sql.

  3. Abra o terminal pelo menu Terminal > Novo Terminal.

  4. Confira se o SQLite está no computador:

    Terminal do VS Code (PowerShell)
    sqlite3 --version
    Deve aparecer um número de versão, como este
    3.54.1 2026-10-16 14:45:20 555e07ef... (64-bit)
    Deu erro?

    Se aparecer que o comando não foi reconhecido, chame o professor.

  5. Abra o banco da aula. Se o arquivo ainda não existir, o SQLite cria:

    Terminal do VS Code (PowerShell)
    sqlite3 aula.db
    Repare

    O começo da linha muda para SQLite-3.54 aula.db->, em cores. A partir daqui, o que você digita vai para o banco de dados, e não para o Windows.

  6. Ajuste a exibição das respostas, uma linha de cada vez:

    Dentro do SQLite
    .headers on
.mode column
Dois tipos de comando

Os que começam com ponto (.tables, .mode, .quit) são do próprio SQLite e não levam ponto e vírgula. Os comandos SQL (CREATE, INSERT, SELECT, UPDATE, DELETE) sempre terminam com ;.

Esqueceu o ponto e vírgula?

A linha seguinte começa só com ;->: é o SQLite avisando que o comando ainda não terminou. Digite ; e aperte Enter.

10 min

Vamos digitar o exemplo da tabela alunos, o mesmo dos slides. Aperte Enter no fim de cada linha.

  1. Crie a tabela:

    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,

INSERT INTO alunos (nome, idade)

Errando de propósito

5 min

Os comandos abaixo estão errados de propósito. Digite um de cada vez e leia a mensagem que o banco devolve. Mesmo em inglês, ela diz o que deu errado.

  1. Comando 1

    Dentro do SQLite
    INSERT INTO alunos (id, nome, idade) VALUES (1, 'Diego Melo', 16);

  2. Comando 2

    Dentro do SQLite
    INSERT INTO alunos (idade) VALUES (16);

  3. Comando 3

    Dentro do SQLite
    SELEC * FROM alunos;

  4. Comando 4

    Dentro do SQLite
    SELECT * FROM aluno;

  5. Comando 5

    Dentro do SQLite
    SELECT * FROM alunos WHERE nome = 'ana souza';
Pergunta para responder

Qual regra da tabela barrou o comando 1? E o comando 2? O comando 5 não deu erro, mas também não mostrou ninguém. Por quê?

Alterar e apagar com cuidado

10 min

  1. Dê nota ao Hades. A turma jogou e deu nota 8.8:

    Dentro do SQLite
    UPDATE jogos SET nota = 8.8
WHERE titulo = 'Hades';
SELECT titulo, nota FROM jogos
WHERE titulo = 'Hades';
    Deve aparecer
    titulo  nota
------  ----
Hades    8.8

  2. Use vírgula no lugar do ponto e leia o erro:

    Dentro do SQLite
    UPDATE jogos SET nota = 9,5
WHERE titulo = 'Celeste';

  3. Apague o jogo mais antigo. Depois, escreva você mesmo um SELECT que mostre os jogos de Puzzle. Quantos sobraram?

    Dentro do SQLite
    DELETE FROM jogos WHERE ano < 2000;

  4. O desastre controlado. Um erro que acontece de verdade é esquecer o WHERE. Faça de propósito:

    Dentro do SQLite
    UPDATE jogos SET nota = 0;
SELECT titulo, nota FROM jogos;
    O que aconteceu

    Todos os jogos ficaram com nota 0.0.

  5. Para desfazer, carregue o arquivo de novo e confira:

    Dentro do SQLite
    .read jogos.sql
SELECT titulo, nota FROM jogos;
    Repare

    As notas voltaram, o Tetris voltou e o Hades ficou de novo sem nota: o arquivo apaga a tabela e cria tudo do zero.

Pergunta para responder

Aqui, o arquivo jogos.sql salvou a tabela. Por que essa saída não existiria no banco de uma loja de verdade, que registra vendas o dia inteiro?
